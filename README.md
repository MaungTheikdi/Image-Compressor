# Image Bulk Compressor

A small Windows-friendly desktop tool for compressing many images at once: pick an **original images folder**, pick an **output folder**, adjust **JPEG quality**, and export everything as optimized JPEGs — without freezing the UI (compression runs on a background thread).

Built with **[CustomTkinter](https://github.com/TomSchimansky/CustomTkinter)** (UI) and **[Pillow](https://python-pillow.org/)** (image I/O and resizing).

## Features

- **Folder in → folder out**: recursively finds images under the source folder and writes compressed files under the output folder.
- **Supported formats** (input): `.jpg`, `.jpeg`, `.png`, `.webp`, `.bmp`, `.tif`, `.tiff`
- **Output**: always **JPEG** (`*_compressed.jpg`) with Pillow `optimize=True`.
- **Max dimension**: long edge capped at **800px** via `thumbnail()` (aspect ratio preserved, LANCZOS resampling).
- **Transparency**: PNG / alpha / paletted images are flattened onto a **white** background before JPEG export (helps avoid muddy or black fringe backgrounds).
- **Subfolders**: relative paths under the original folder are **mirrored** in the output tree.
- **Nested output**: if the output folder lives *inside* the source tree, files under that output path are **excluded** from scanning so freshly written JPEGs are not picked up as new inputs on the next scan.
- **Guards**: source and destination cannot be the same folder.
- Progress bar, rough **input/output size** summary after a run, and per-file **error reporting** when something fails.

## Requirements

- **Python** 3.10+ recommended (CustomTkinter and Pillow supported versions).

## Setup

Clone the repo, then install dependencies:

```bash
pip install -r requirements.txt
```

If `pip` is not on your PATH (common on Windows), use:

```bash
py -m pip install -r requirements.txt
```

## Run

```bash
python main.py
```

or:

```bash
py main.py
```

## Build a standalone `.exe` (Windows)

Install PyInstaller, then bundle CustomTkinter assets:

```bash
py -m pip install pyinstaller
py -m PyInstaller --noconsole --onefile --name ImageCompressor --collect-all customtkinter main.py
```

After a successful build, open **`dist/ImageCompressor.exe`**.

You can reuse the checked-in **`ImageCompressor.spec`** (generated by PyInstaller) for repeat builds:

```bash
py -m PyInstaller ImageCompressor.spec
```
